# Coffee Sales Dashboard

A sales dashboard built in Microsoft Excel to explore and visualize coffee sales data across three countries.

---

## What This Project Is

This is an Excel dashboard project that takes raw coffee sales data and turns it into an interactive visual report. You can use the dashboard to filter and explore the data by coffee type, roast, package size, and loyalty card status.

## Tools Used

- **Microsoft Excel** — the entire project is built in Excel
- **Pivot Tables** — used to summarize the sales data
- **Pivot Charts** — used to display the data visually
- **Slicers** — used to make the dashboard interactive and filterable
- **XLOOKUP & INDEX-MATCH** — used to pull customer and product details into the orders sheet
- **Data Validation** — used to keep the data clean and consistent

---

## Dataset

The data covers coffee orders from customers in three countries: the United States, Ireland, and the United Kingdom.

Each order includes details like the customer name, country, coffee type, roast type, package size, quantity, and total sale value.

The workbook has five sheets:

- **orders** — the raw transaction data
- **customers** — customer details
- **products** — product details and pricing
- **Dashboard** — the main interactive dashboard
- **Total Sales, Country Bar Chart, Top 5 Customers** — supporting charts and pivot tables that feed the dashboard

---

## How to Use

1. Download the file and open it in Microsoft Excel (2016 or later)
2. Go to the **Dashboard** sheet
3. Use the slicers on the dashboard to filter by:
   - Coffee Type (Arabica, Excelsa, Liberica, Robusta)
   - Roast Type (Light, Medium, Dark)
   - Package Size (0.2 kg, 0.5 kg, 1 kg, 2.5 kg)
   - Loyalty Card (Yes / No)
4. The charts will update automatically based on your selections
